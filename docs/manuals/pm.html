คู่มือสำหรับ Project Manager

การตรวจสอบ อนุมัติ และควบคุมแผนงานเครื่องจักร-อุปกรณ์ระดับโครงการ

1. บทบาทและอำนาจการตัดสินใจ

ในฐานะ Project Manager คุณคือผู้อนุมัติขั้นสุดท้ายของแผนการใช้อุปกรณ์ในแต่ละรอบงานก่อสร้าง อำนาจของคุณคือการตัดสินใจว่าแผนที่ Site Planner เสนอมานั้นเหมาะสมกับหน้างานจริงและงบประมาณหรือไม่

2. การตรวจสอบแผนงาน (PM Review)

เมื่อเข้าสู่เมนู Site Planning > PM Approval คุณจะเห็นรายการโครงการที่ Site Planner ส่งเข้ามาเพื่อรอการอนุมัติ

ความสามารถในการแก้ไขแผนงานก่อนอนุมัติ

หากคุณพบว่าจำนวนที่ขอมามากหรือน้อยเกินไป คุณสามารถ "แก้ไขจำนวน" ได้โดยตรงในหน้าจอนี้ ระบบจะทำการ Update ข้อมูลใหม่ให้อัตโนมัติเมื่อมีการบันทึกการตัดสินใจ

3. การอนุมัติและการปฏิเสธงาน (Approve/Reject)

การตัดสินใจของคุณมี 2 รูปแบบหลัก:

Approve (อนุมัติ)

แผนงานจะถูกส่งต่อไปยัง Store Center เพื่อเตรียมการจัดซื้อ/เช่า หรือจัดส่งอุปกรณ์ทันที ข้อมูลนี้จะถือเป็นยอดสรุปของบริษัท

Reject (ส่งกลับแก้ไข)

ระบบจะส่งแผนงานกลับไปให้ Site Planner แก้ไขใหม่ คุณควรระบุเหตุผลในการ Reject เพื่อให้ทีมงานหน้างานทราบจุดที่ต้องปรับปรุง

4. การติดตามภาพรวม (PM Dashboard)

นอกจากงานที่รออนุมัติแล้ว คุณยังสามารถใช้หน้า Matrix Report เพื่อดูสถานะการใช้อุปกรณ์จริงเทียบกับแผนงาน (Actual vs Plan) เพื่อใช้ในการบริหารความเสี่ยงและงบประมาณของโครงการในภาพรวมได้

คู่มือสำหรับ Store Site (หน้างาน)

ขั้นตอนการวางแผนและจัดการความต้องการอุปกรณ์ระดับโครงการ

1. บทบาทและหน้าที่ (Role & Responsibilities)

ในฐานะ Store Site คุณคือผู้เชื่อมโยงความต้องการจากหน้างานจริงเข้าสู่ระบบ หน้าที่หลักของคุณคือการวางแผนการใช้อุปกรณ์รายเดือน (Monthly Planning) และควบคุมยอดสต็อกหน้างานให้สอดคล้องกับแผนงานก่อสร้าง

2. การใช้งาน Interactive Worksheet

Worksheet คือหัวใจสำคัญที่คุณต้องระบุจำนวนความต้องการอุปกรณ์ในแต่ละเดือน

1

การระบุจำนวน (Input Quantity)

คลิกที่ช่องเดือนที่ต้องการ แล้วพิมพ์จำนวนอุปกรณ์ที่ต้องใช้ ระบบจะคำนวณยอดรวมและตรวจสอบความพร้อมของสต็อกเบื้องต้นให้ทันที

2

การบันทึกฉบับร่าง (Save Draft)

หากยังวางแผนไม่เสร็จ คุณสามารถกด Save Draft เพื่อกลับมาทำต่อภายหลังได้ ข้อมูลนี้จะยังไม่ถูกส่งไปให้ PM ตรวจสอบ

3. กระบวนการส่งงาน (Submission Workflow)

เมื่อมั่นใจในตัวเลขการวางแผนแล้ว ให้ดำเนินการส่งแผนงานเพื่อให้ PM พิจารณาอนุมัติ

ปุ่ม Submit Planning

หลังจากกดแล้ว สถานะของงานจะเปลี่ยนเป็น "SUBMITTED" และคุณจะไม่สามารถแก้ไขข้อมูลได้จนกว่า PM จะส่งกลับมา (Reject)

ข้อควรระวัง

โปรดตรวจสอบจำนวนอุปกรณ์ให้ถูกต้องตามแผนงานจริง เนื่องจากข้อมูลนี้จะถูกนำไปคำนวณยอดจัดซื้อของบริษัทในภาพรวม

4. การตรวจสอบยอดค้างรับ-ค้างส่ง

ในตาราง Matrix ระบบจะแสดงคอลัมน์พิเศษที่ช่วยให้คุณบริหารจัดการหน้างานได้ง่ายขึ้น:

  • Site Stock: จำนวนอุปกรณ์ที่มีอยู่จริงที่หน้างานปัจจุบัน
  • Pending Receipt: ยอดอุปกรณ์ที่รอรับเข้าตามแผนการอนุมัติ
  • Net Requirement: ยอดความต้องการสุทธิที่บริษัทต้องจัดหาเพิ่มเติมให้คุณ

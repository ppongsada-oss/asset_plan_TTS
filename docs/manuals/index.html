Learning Center

คู่มือการใช้งาน ASSET PLAN

เลือกบทบาทของคุณเพื่อเริ่มต้นเรียนรู้วิธีการใช้งานระบบอย่างละเอียด

System Administrator

การตั้งค่าระบบ, จัดการผู้ใช้, ข้อมูลโครงการ และการบริหารจัดการ Master Data อุปกรณ์กลาง

เปิดคู่มือ

Store Site (หน้างาน)

ขั้นตอนการวางแผนความต้องการอุปกรณ์รายเดือน, การบันทึกสต็อก และการส่งงานเพื่ออนุมัติ

เปิดคู่มือ

Project Manager

กระบวนการตรวจสอบแผนงาน, การปรับแก้ไขจำนวน และการอนุมัติ/ปฏิเสธงาน (Governance)

เปิดคู่มือ

Store Center (ส่วนกลาง)

การวิเคราะห์ Demand รวม, การบริหารจัดการสต็อกส่วนกลาง, และการตัดสินใจจัดซื้อ/เช่าอุปกรณ์

เปิดคู่มือ

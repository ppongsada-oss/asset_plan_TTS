คู่มือสำหรับ System Administrator

การบริหารจัดการสิทธิ์ ข้อมูลโครงการ และฐานข้อมูลอุปกรณ์กลาง

1. บทนำ (Introduction)

ในฐานะ System Administrator คุณคือผู้ควบคุมโครงสร้างหลักของระบบ Asset Plan หน้าที่หลักของคุณคือการดูแลความถูกต้องของข้อมูลพื้นฐาน (Master Data) และการจัดการสิทธิ์ของผู้ใช้งานเพื่อให้กระบวนการวางแผนดำเนินไปได้อย่างราบรื่น

คำเตือน: การลบข้อมูลในส่วน Admin อาจส่งผลกระทบต่อแผนงานที่กำลังดำเนินการอยู่ โปรดตรวจสอบก่อนทุกครั้ง

2. การจัดการผู้ใช้งาน (User Management)

คุณสามารถเพิ่ม แก้ไข หรือระงับสิทธิ์ผู้ใช้งานได้จากหน้าจอ Admin > Users

1

การเพิ่มผู้ใช้ใหม่

กรอก Email และกำหนดรหัสผ่านเบื้องต้น พร้อมเลือก Global Role (ADMIN หรือ USER)

2

การเปลี่ยนรหัสผ่าน

หากผู้ใช้ลืมรหัสผ่าน คุณสามารถใช้ปุ่ม Edit เพื่อ Reset รหัสผ่านใหม่ได้

3. การจัดการโครงการและสิทธิ์ (Projects & Roles)

ระบบ Asset Plan ใช้การควบคุมสิทธิ์ระดับโครงการ (Project-based Access) หมายความว่า Site Planner หรือ PM จะมองเห็นเฉพาะโครงการที่ได้รับมอบหมายเท่านั้น

สร้างโครงการ

กำหนดรหัสโครงการ (Project Code) และชื่อโครงการ เพื่อเริ่มวงจรการวางแผน

มอบหมายบทบาท

ในหน้า Project Roles ให้เลือกโครงการและระบุว่าใครคือ PM หรือ Site Planner

4. การจัดการ Master Data อุปกรณ์

ข้อมูลอุปกรณ์ก่อสร้างทั้งหมดจะถูกเก็บไว้ที่ Master Data เพื่อเป็นมาตรฐานเดียวกันทั้งองค์กร

Bulk Upload (CSV)

แนะนำให้ใช้ปุ่ม "Download Template" เพื่อดาวน์โหลดรูปแบบไฟล์ที่ถูกต้องก่อนทำการ Upload ข้อมูลอุปกรณ์จำนวนมาก

Stock Calibration

ทุกครั้งที่มีการเริ่มรอบการวางแผนใหม่ (Cycle) แอดมินต้องทำการ Update ยอดสต็อกตั้งต้นผ่านระบบ Import เพื่อให้หน้างานมีฐานข้อมูลที่แม่นยำ

ผู้ดูแลระบบ ข้อมูลโครงการ และสิทธิ์การใช้งาน

Store Site (หน้างาน)

ผู้ตรวจสอบและอนุมัติแผนการใช้อุปกรณ์

ผู้บริหารทรัพยากรส่วนกลางและแผนการจัดซื้อ

Role 01

System Administrator

ผู้ควบคุมและกำหนดทิศทางข้อมูลพื้นฐาน เพื่อให้ทุกโครงการทำงานบนมาตรฐานเดียวกัน

  • จัดการผู้ใช้งานและกำหนดสิทธิ์เข้าถึง (User Management)
  • บริหารโครงการและคลังสินค้า (Project/Warehouse Management)
  • จัดการข้อมูลอุปกรณ์กลาง (Global Equipment Master)
Role 02

Store Site

ผู้รวบรวมข้อมูลความต้องการจริงจากหน้างาน เพื่อการวางแผนล่วงหน้าที่แม่นยำ

  • วางแผนความต้องการอุปกรณ์รายเดือน (Demand Planning)
  • บริหารจัดการสต็อกและยอดค้างรับหน้างาน
  • ส่งข้อมูลเข้าสู่ระบบเพื่อการตรวจสอบโดย Project Manager
Role 03

Project Manager

ผู้ดูแลความถูกต้องและงบประมาณ ตรวจสอบความเหมาะสมของแผนก่อนดำเนินการ

  • ตรวจสอบแผนงานเปรียบเทียบกับงบประมาณโครงการ
  • ปรับแก้ไขข้อมูลแผนงาน (Planning Adjustments)
  • พิจารณาอนุมัติ (Approve) เพื่อส่งข้อมูลไปยังสโตร์กลาง
Role 04

Store Center

ศูนย์กลางการตัดสินใจและบริหารจัดการทรัพยากรในภาพรวมขององค์กร

  • วิเคราะห์ยอดความต้องการรวม (Net Demand) จากทุกไซต์งาน
  • บริหารแผนการจัดส่งและการหมุนเวียนอุปกรณ์ (Circulation)
  • วางแผนจัดซื้อและเช่าอุปกรณ์เพิ่ม (Procurement Decisions)

Matrix Reporting

มุมมองระดับบริหาร (Executive View) ที่รวบรวมข้อมูลจากทุกภาคส่วนเพื่อการตัดสินใจที่รวดเร็ว

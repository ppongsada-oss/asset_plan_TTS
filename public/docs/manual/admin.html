คู่มือผู้ดูแลระบบ (Admin)

การตั้งค่าระบบ จัดการผู้ใช้ โครงการ และข้อมูลครุภัณฑ์

สิทธิ์ที่ใช้ ADMIN
เส้นทางหลัก /admin, /master-data
ทำก่อนเริ่มใช้งาน ตั้งค่า User + Project + Role
📌 ลำดับการตั้งค่าครั้งแรก: Master Data → โครงการ → ผู้ใช้ → Project Roles → สร้างรอบแผน
1

จัดการข้อมูลครุภัณฑ์ (Master Data) — /master-data

ข้อมูลครุภัณฑ์เป็นฐานของทุกอย่างในระบบ ต้องตั้งค่าก่อนเริ่มใช้งาน

วิธีเพิ่มครุภัณฑ์ทีละรายการ:

  1. ไปที่เมนู Master Data
  2. กดปุ่มเพิ่มรายการ → กรอกรหัส, ชื่อ, หน่วย, ราคาซื้อ, ราคาเช่า, สต็อกคงเหลือ
  3. บันทึก

วิธี Import หลายรายการด้วย CSV:

  1. กด "โหลด Template CSV" เพื่อดาวน์โหลด Template
  2. เปิดใน Excel หรือ Numbers แล้วกรอกข้อมูล
  3. บันทึกเป็น CSV (UTF-8)
  4. กด "อัปโหลดข้อมูล (Bulk)" → เลือกไฟล์ CSV
  5. ตารางจะ Refresh อัตโนมัติ
⚠️ remaining_stock ใน Master Data คือสต็อกคลังกลางที่ทุกหน้าในระบบแสดง — แก้ไขค่านี้จะกระทบ Center Dashboard ทันที
2

จัดการโครงการ — /admin/projects

สร้างโครงการใหม่:

  1. กด "สร้างโครงการ"
  2. กรอกชื่อโครงการ และเลือกประเภท:
    • SITE — ไซต์งาน (กรอกแผนและรับของ)
    • WAREHOUSE — คลังกลาง (เก็บสต็อก)
  3. บันทึก

Archive โครงการ: โครงการที่เสร็จแล้วหรือไม่ใช้งาน — Archive เพื่อซ่อนออกจากรายการปกติ (ข้อมูลยังคงอยู่)

💡 Matrix Report มีตัวเลือก "แสดงโครงการ Archive" เพื่อดูข้อมูลเก่าได้
3

จัดการผู้ใช้งาน — /admin/users

สร้างผู้ใช้ใหม่:

  1. กด "เพิ่มผู้ใช้"
  2. กรอก Email (บังคับ) และ Password (บังคับสำหรับสร้างใหม่)
  3. เลือก Global Role:
    • USER — ผู้ใช้ทั่วไป (ต้องกำหนด Project Role เพิ่ม)
    • STORE_CENTER — ทีมคลังกลาง เข้า Store Center ได้
    • ADMIN — ผู้ดูแลระบบ เข้าได้ทุกหน้า
  4. บันทึก

แก้ไขผู้ใช้: แก้ Email หรือ Password ได้ (Password ปล่อยว่างถ้าไม่ต้องการเปลี่ยน)

⚠️ ลบผู้ใช้: เป็นการลบถาวร (Hard Delete) — ไม่มีฟีเจอร์ปิดการใช้งานชั่วคราว ระบบแสดง Confirm ก่อนลบทุกครั้ง
4

กำหนดสิทธิ์ต่อโครงการ — /admin/project-roles

กำหนดว่าใครมีสิทธิ์อะไรในโครงการไหน ผู้ใช้ 1 คนมีได้หลาย Role ในหลายโครงการ

ขั้นตอนกำหนด Role:

  1. เลือก ผู้ใช้ จากรายการ
  2. ค้นหาและ เลือกโครงการ (Checkbox — เลือกได้หลายโครงการพร้อมกัน)
    • มีปุ่ม "เลือกทั้งหมด" / "ล้าง" สำหรับผลการค้นหาปัจจุบัน
  3. เลือก Role ที่ต้องการกำหนด
  4. กด "Confirm Assignment"

3 Project Roles ที่ใช้ได้:

Roleสิทธิ์ในโครงการนั้น
STORE_SITE — ผู้กรอกแผนกรอก แก้ไข และส่งแผนได้
PROJECT_MANAGER — ผู้อนุมัติตรวจสอบ อนุมัติ หรือตีกลับแผน
VIEWER — ผู้ดูอย่างเดียวดูข้อมูลได้ แต่ปุ่มแก้ไขทั้งหมดซ่อน

การอ่านตาราง Assignment ที่มีอยู่:

  • จัดกลุ่มตาม ผู้ใช้ + Role — แสดง 3 โครงการแรก + "+N more"
  • Hover ที่ "+N more" เพื่อดูรายชื่อทั้งหมด
  • กด Delete → ลบ ทุกโครงการ ของ User+Role Group นั้นพร้อมกัน

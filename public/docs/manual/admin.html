คู่มือผู้ดูแลระบบ (Admin)

ตั้งค่าข้อมูลหลัก จัดการผู้ใช้ โครงการ และสิทธิ์การเข้าถึง — ทำก่อนทีมเริ่มใช้งานระบบ

สิทธิ์ที่ใช้ ADMIN
เส้นทางหลัก /admin, /master-data
ทำก่อนเริ่มใช้งาน ครั้งเดียว ทำครั้งแรกให้ครบ
📌 ลำดับการตั้งค่าครั้งแรก (ห้ามข้าม): Master Data → โครงการ → ผู้ใช้ → Project Roles → Store Center สร้างรอบแผน
⚙️ ขั้นตอนที่ 1 — ข้อมูลครุภัณฑ์ (Master Data)
1

ภาพรวมหน้า Master Data — /master-data

Master Data คือรายการครุภัณฑ์ทั้งหมดในระบบ ทุกหน้าในระบบอ้างอิงข้อมูลจากที่นี่ ต้องตั้งค่าก่อนสร้างรอบแผนเสมอ

หน้า Master Data มี 3 แท็บ:

แท็บใช้ทำอะไร
รายการอุปกรณ์ดูรายการครุภัณฑ์ทั้งหมด, เพิ่ม/แก้ไข/ลบรายการ
ตั้งค่าหมวดหมู่กำหนดกลุ่มครุภัณฑ์สำหรับกรอง
Remaining Stockอัปเดตสต็อกคลังกลางเป็นชุด (Bulk)
2

ตั้งค่าหมวดหมู่ครุภัณฑ์ (แท็บ: ตั้งค่าหมวดหมู่)

หมวดหมู่ใช้สำหรับกรองรายการในหน้า Site Worksheet และ PM Review — ตั้งค่าก่อนเพิ่มครุภัณฑ์จะทำให้จัดกลุ่มได้ทันที

  1. คลิกแท็บ "ตั้งค่าหมวดหมู่"
  2. กด "+ เพิ่มหมวดหมู่" → กรอกชื่อหมวดหมู่
  3. กด "ดูตัวอย่าง" เพื่อเห็นว่าครุภัณฑ์จะถูกจัดกลุ่มอย่างไรในแบบฟอร์ม
💡 ตัวอย่างหมวดหมู่ที่ใช้บ่อย: เครื่องจักรหนัก, ยานพาหนะ, เครื่องมือไฟฟ้า, อุปกรณ์นิรภัย
3

เพิ่มรายการครุภัณฑ์ (แท็บ: รายการอุปกรณ์)

มี 2 วิธี — เพิ่มทีละรายการ หรือนำเข้าครั้งละหลายรายการ

วิธีที่ 1 — เพิ่มทีละรายการ:

  1. คลิก "จัดการรายการสินค้า" → เลือก "เพิ่มรายการใหม่"
  2. กรอกข้อมูล: รหัส, ชื่อ, หน่วย, ราคาซื้อ, ราคาเช่า, หมวดหมู่
  3. กด "บันทึก"

วิธีที่ 2 — นำเข้าจาก CSV (Bulk Import):

  1. คลิก "จัดการรายการสินค้า" → เลือก "Import จาก CSV"
  2. กด "โหลด Template CSV" ก่อน → เปิดใน Excel แล้วกรอกข้อมูล
  3. บันทึกไฟล์เป็น CSV (UTF-8) → กด "อัปโหลด"
  4. ตารางจะ Refresh อัตโนมัติเมื่อนำเข้าสำเร็จ
⚠️ ชื่อคอลัมน์ใน CSV ต้องตรงกับ Template ทุกตัวอักษร — ถ้าผิด ระบบจะแจ้ง Error ก่อน Import
4

อัปเดตสต็อกคลังกลาง (แท็บ: Remaining Stock)

Remaining Stock คือจำนวนที่คลังกลางมีอยู่ปัจจุบัน — ค่านี้แสดงใน Center Dashboard และใช้คำนวณความต้องการสุทธิ

อัปเดตด้วย CSV (วิธีเดียวที่รองรับ Bulk):

  1. คลิก "จัดการ Remaining Stock" → เลือก "อัปโหลดยอดคงเหลือ"
  2. กด "โหลด Template" → กรอกจำนวนสต็อกปัจจุบันในคอลัมน์ remaining_stock
  3. อัปโหลดไฟล์ → ค่าในระบบจะอัปเดตทันที
⚠️ การอัปโหลดจะ Overwrite ค่าเดิมทั้งหมด — ตรวจสอบตัวเลขให้ถูกต้องก่อนกดอัปโหลด
🏗️ ขั้นตอนที่ 2 — จัดการโครงการ
5

สร้างและจัดการโครงการ — /admin/projects

โครงการคือหน่วยงานหลักในระบบ ทุก Planning Job ผูกกับโครงการ ต้องสร้างโครงการก่อนกำหนดสิทธิ์ผู้ใช้

สร้างโครงการใหม่:

  1. กด "+ สร้างโครงการ"
  2. กรอกชื่อโครงการ และเลือกประเภท:
    • SITE — ไซต์งาน (กรอกแผนและรับครุภัณฑ์)
    • WAREHOUSE — คลังกลาง (เก็บและจัดสรรสต็อก)
  3. กด "บันทึก"

กรองและค้นหาโครงการ:

  • แท็บ "ทั้งหมด" — แสดงทุกโครงการที่ Active
  • แท็บ "ไซต์งาน" — กรองเฉพาะประเภท SITE
  • ปุ่ม "Archived" — ดูโครงการที่ Archive แล้ว

Archive โครงการที่เสร็จแล้ว:

โครงการที่ Archive ยังมีข้อมูลทั้งหมดอยู่ครบ — แค่ซ่อนออกจากรายการปกติเพื่อไม่ให้รก ดูย้อนหลังได้เสมอ

💡 Matrix Report มีตัวเลือก "แสดงโครงการ Archive" เพื่อรวมข้อมูลเก่าในรายงาน
👤 ขั้นตอนที่ 3 — จัดการผู้ใช้งาน
6

เพิ่มและจัดการบัญชีผู้ใช้ — /admin/users

ผู้ใช้ทุกคนต้องมีบัญชีในระบบก่อนเข้าใช้งาน — Global Role กำหนดหน้าที่เข้าถึงได้ทันที

สร้างผู้ใช้ใหม่:

  1. กด "+ เพิ่มผู้ใช้"
  2. กรอก Email และ Password (Password บังคับเมื่อสร้างใหม่)
  3. เลือก Global Role ตามตาราง:
Global Roleเข้าถึงได้ใช้สำหรับ
USER เฉพาะหน้าที่ได้รับ Project Role กำหนด พนักงานไซต์, PM — ต้องกำหนด Project Role เพิ่ม
STORE_CENTER Store Center + Reports เจ้าหน้าที่คลังกลาง
ADMIN ทุกหน้าในระบบ ผู้ดูแลระบบเท่านั้น

แก้ไขข้อมูลผู้ใช้: กดไอคอน ✏️ ข้างชื่อ → แก้ Email หรือ Password ได้ (ปล่อย Password ว่างถ้าไม่ต้องการเปลี่ยน)

⚠️ ลบผู้ใช้: ลบถาวร (Hard Delete) — ไม่มีฟีเจอร์ปิดชั่วคราว ระบบแสดงกล่องยืนยันก่อนทุกครั้ง
🔑 ขั้นตอนที่ 4 — กำหนดสิทธิ์ต่อโครงการ
7

กำหนด Project Roles — /admin/project-roles

Project Role กำหนดว่าผู้ใช้ที่มี Global Role = USER สามารถทำอะไรได้ในโครงการใด ผู้ใช้ 1 คนมีได้หลาย Role ในหลายโครงการ

3 Project Roles:

Roleสิทธิ์ในโครงการนั้น
STORE_SITEกรอก แก้ไข และ Submit แผนความต้องการได้
PROJECT_MANAGERตรวจสอบ แก้ตัวเลข อนุมัติ หรือตีกลับแผน
VIEWERดูข้อมูลได้อย่างเดียว — ปุ่มแก้ไขทั้งหมดซ่อน

วิธีกำหนด Role:

  1. เลือก ผู้ใช้ จากรายการด้านซ้าย
  2. ค้นหาและ Tick โครงการ ที่ต้องการ (เลือกได้หลายโครงการพร้อมกัน)
  3. เลือก Role ที่จะกำหนด
  4. กด "Confirm Assignment"

อ่านตาราง Assignment ที่มีอยู่:

  • จัดกลุ่มตาม ผู้ใช้ + Role — แสดง 3 โครงการแรก + "+N more"
  • Hover ที่ "+N more" เพื่อดูรายชื่อทั้งหมด
  • กด Delete → ลบทุกโครงการของ User+Role Group นั้นพร้อมกัน
💡 หลังกำหนด Role ครบ → ถัดไปคือ Store Center สร้างรอบแผน เพื่อเปิดให้ไซต์กรอกข้อมูลได้
👤 ข้อมูลส่วนตัว — ทุก Role ใช้ได้
8

Navbar และการออกจากระบบ

ทุก Role เข้าถึงข้อมูลส่วนตัวผ่าน Avatar Button มุมขวาบนของ Navbar

  • โปรไฟล์ — ดูและแก้ไขชื่อ, อีเมล, รหัสผ่าน
  • ออกจากระบบ — Logout ออกจาก Session ปัจจุบัน
💡 การเปลี่ยนรหัสผ่านทำได้จากหน้า Profile โดยไม่ต้องให้ Admin แก้ให้

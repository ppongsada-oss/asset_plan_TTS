หน้าแรก Admin Store Site PM Center Reports

คู่มือผู้ดูแลระบบ (Admin)

การจัดการข้อมูลพื้นฐานและตั้งค่าระบบ

1

จัดการข้อมูลอุปกรณ์ (Master Data)

เมนู Master Data ใช้สำหรับเพิ่ม/แก้ไขรายการอุปกรณ์ ราคาซื้อ/เช่า และการอัปโหลดข้อมูลสต็อกคงเหลือรวมของบริษัทผ่าน CSV

2

จัดการงวดงาน (Planning Cycle)

Admin หรือ Center สามารถสร้างงวดงานใหม่เพื่อกำหนดช่วงเวลาที่ต้องการให้ไซต์งานทำการวางแผน

3

จัดการผู้ใช้งานและสิทธิ์ (User & Roles)

เมนู Admin -> Users และ Admin -> Project Roles ใช้สำหรับสร้างบัญชีผู้ใช้และกำหนดว่าใครมีสิทธิ์เข้าถึงโครงการใดในบทบาทอะไร

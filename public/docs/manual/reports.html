คู่มือ Matrix Report

รายงานภาพรวมความต้องการและสต็อกครุภัณฑ์ทั้งบริษัท

สิทธิ์ที่ใช้ STORE_CENTER / ADMIN
เส้นทาง เมนู → Matrix Report
ใช้ร่วมกับ Center Dashboard
1

ภาพรวม — ตาราง Matrix คืออะไร

Matrix Report แสดงความต้องการครุภัณฑ์ทุกรายการ เปรียบเทียบระหว่างทุกโครงการในรูป Pivot Table

  • แถว (Row) = ครุภัณฑ์แต่ละรายการ
  • คอลัมน์ไซต์ สีน้ำเงิน = จำนวนที่แต่ละไซต์วางแผนไว้ (Peak qty)
  • คอลัมน์คลัง สีเขียว = สต็อกของคลังกลางแต่ละแห่ง
  • คอลัมน์สรุป = ตัวเลขรวมและสถานะการดำเนินการ
💡 ค่า 0 แสดงเป็น "–" (ขีด) เพื่อให้อ่านตารางง่ายขึ้น — ค่าที่มีตัวเลขเท่านั้นที่ต้องสนใจ
2

อ่านคอลัมน์สรุป

คอลัมน์ด้านขวาของตารางสรุปสถานะการดำเนินงาน:

คอลัมน์ความหมาย
D รวมDemand สุทธิรวมทุกไซต์ (ความต้องการ − ของที่ไซต์มีอยู่แล้ว)
เบิกรวมที่ DISPATCH แล้ว
หมุนรวมที่ CIRCULATE แล้ว
สลับรวมที่ SUBSTITUTE แล้ว
ซื้อรวมที่ BUY แล้ว
เช่ารวมที่ RENT แล้ว
ค้างส่ง DDemand ที่ยังไม่ได้จัดสรร — ต้องดำเนินการ
S รวมรวมที่ไซต์จะส่งคืน (Expected Returns)
ยอดคืนรวมที่ RECEIVE แล้ว
ปฏิเสธรวมที่ REJECT_RETURN แล้ว
ค้างรับ Rยอดส่งคืนที่ยังไม่ได้รับ — ต้องดำเนินการ
📌 ค้างส่ง D และ ค้างรับ R คือตัวเลขที่ต้องสนใจที่สุด — ถ้ายังมีค่า หมายความว่ายังมีงานค้างอยู่
3

การใช้ Filter และ Sort

ตัวกรอง:

  • รอบแผน — เลือกรอบ → ระบบเลือก Months ให้อัตโนมัติ
  • เดือน — Toggle แต่ละเดือนอิสระ (Multi-select คลิกเปิด/ปิดได้)
  • "แสดง Archive" — เปิด/ปิดโครงการที่ Archive แล้ว
  • "ต้องดำเนินการ" — กรองเฉพาะแถวที่มี ค้างส่ง D > 0 หรือ S รวม > 0

Sort: คลิก header คอลัมน์ใดก็ได้ — ขึ้น → ลง → Reset

Default Sort: แถวที่มี Pending Demand/Receipt ลอยขึ้นก่อนเสมอ

💡 วิธีใช้งานที่แนะนำ: เลือกรอบแผน → กด "ต้องดำเนินการ" → ดูเฉพาะแถวที่ยังค้างอยู่ → ไปดำเนินการที่ Center Dashboard
4

Hover Tooltip — ดูรายละเอียดรายโครงการ

วางเมาส์บนตัวเลขใดก็ได้ในตาราง → Tooltip แสดง Breakdown:

  • ชื่อโครงการ
  • จำนวนที่ต้องการ (Gross Required)
  • คาดว่าจะคืน (Expected Return)
  • ยอดสุทธิ (Net)
  • Breakdown รายเดือน
💡 ใช้ Tooltip เพื่อตรวจสอบว่าโครงการไหนเป็นผู้ขอ/ผู้ส่งคืน โดยไม่ต้องออกจาก Matrix Report
5

Export ข้อมูล — 2 รูปแบบ

ปุ่มเนื้อหาใช้เมื่อชื่อไฟล์
Export All ตาราง Matrix ทั้งหมด (2 Sheet: Demand + Return) ทำรายงานสรุปภาพรวมผู้บริหาร Matrix_Report_YYYY-MM-DD.xlsx
Export Procurement เฉพาะรายการ BUY + RENT แยกรายโครงการ/เดือน ส่งให้ฝ่ายจัดซื้อดำเนินการ Procurement_Plan_YYYY-MM-DD.xlsx
⚠️ ถ้ากด Export Procurement แล้วไม่มีรายการ → ระบบแจ้ง: "ไม่มีรายการจัดซื้อหรือจัดเช่าในขณะนี้" — หมายความว่ายังไม่มีการ BUY หรือ RENT ในรอบนั้น

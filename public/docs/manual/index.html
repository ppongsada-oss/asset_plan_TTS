Admin

ตั้งค่าระบบ จัดการข้อมูลครุภัณฑ์ สร้างโครงการ กำหนดผู้ใช้และสิทธิ์

4 ขั้นตอน — ทำก่อนเริ่มใช้งาน เข้าดูคู่มือ Admin → STORE_SITE

Store Site

กรอกแผนความต้องการพัสดุรายเดือน บันทึกยอดคงเหลือหน้างาน และส่งแผนให้ PM

5 ขั้นตอน — ทำทุกรอบแผน เข้าดูคู่มือ Site → PROJECT_MANAGER

Project Manager

ตรวจสอบความถูกต้องของแผน แก้ไขตัวเลข อนุมัติหรือตีกลับแผนให้ไซต์

5 ขั้นตอน — หลังไซต์ Submit เข้าดูคู่มือ PM → STORE_CENTER

Store Center

สร้างรอบแผน Lock/Unlock ใบงาน จัดสรรครุภัณฑ์ด้วย 5 วิธี และบริหารของคืน

10 ขั้นตอน — หลัก PM อนุมัติ เข้าดูคู่มือ Center →
STORE_CENTER / ADMIN

▼
Phase 2 — สร้างรอบแผน (Planning Cycle)
Store Center กำหนดขอบเขตและเปิดรอบแผน
กด "+ สร้างรอบแผนใหม่" — กรอก วันเริ่ม / Deadline / เดือนเป้าหมาย (1–12 เดือน)
เลือกโครงการที่เข้าร่วม — ค้นหา, เลือกทีละรายการ หรือ "เลือกทั้งหมด"
กด "สร้าง"
ระบบสร้างอัตโนมัติ — Job 1 ใบต่อ 1 โครงการ สถานะ OPEN พร้อมให้ทุกไซต์กรอกแผนทันที
วันที่และเดือนเป้าหมาย แก้ไขไม่ได้หลังสร้าง — แก้ไขได้เฉพาะโครงการที่เข้าร่วม
▼
Phase 3 — กรอกแผนความต้องการ
Store Site วางแผนรายเดือนล่วงหน้า OPEN
เปิดหน้า Site Plan → เห็น Job ของโครงการตัวเอง พร้อม Countdown ถึง Deadline
คลิก "เริ่มวางแผน" → เข้าตาราง Worksheet (แถว = ครุภัณฑ์, คอลัมน์ = เดือน)
พิมพ์จำนวน → กด Enter Auto-fill เดือนที่เหลือ + เลื่อนแถวถัดไป
ระบบแสดง คืน X อัตโนมัติ เมื่อจำนวนลดลงจากเดือนก่อน
บันทึกฉบับร่าง — สถานะยัง OPEN กลับมาแก้ได้เสมอ
|
ส่งแผน (Submit) — ล็อกตาราง สถานะ → SUBMITTED
▼
Phase 4 — ตรวจสอบและอนุมัติ
Project Manager ตรวจสอบ แก้ไข และตัดสินใจ SUBMITTED
เปิดหน้า PM Approval → เห็น Job ที่รออนุมัติทุกโครงการที่ตัวเองเป็น PM
ใช้ Mode Filter เพื่อโฟกัส: DEMAND (ขอเพิ่ม) · RETURN (จะคืน) · CHANGED (แก้แล้ว)
แก้ไขตัวเลขในตารางได้โดยตรง → ระบบ Log ทุก Cell → ดูย้อนหลังใน Mode CHANGED
ตัดสินใจ
?
อนุมัติ (Approve)
บันทึกการแก้ไข → ส่งข้อมูลให้ Store Center ทันที
SUBMITTED → APPROVED
ตีกลับ (Reject)
กรอกเหตุผล → ไซต์แก้ไขและส่งใหม่
SUBMITTED → OPEN ↩ Phase 3
ตีกลับ → ไซต์แก้ไขแล้วส่งใหม่ (วนซ้ำ Phase 3–4)
APPROVED — ข้อมูลส่งต่อ Store Center

Phase 6 — รับของคืน (Returns)
Store Center หน้า Net Demand — แท็บ "รายการส่งคืน"

รายการที่ไซต์มีของ เกินกว่าที่วางแผน — ระบบคำนวณยอดคืนให้อัตโนมัติจากแผนที่อนุมัติ

รับคืน (RECEIVE)
